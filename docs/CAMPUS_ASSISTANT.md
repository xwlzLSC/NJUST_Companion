# 校历图片 / 主修学业审查

本版按最新要求收敛为两个校园模块。首页仍保留原有课表、成绩、考试、待办、图书检索等功能。

## 保留的功能

- 校历图片：显示 2026–2027 官方校历，点击放大查看。小程序使用微信原生预览、双指缩放；网页/APK 使用原图滚动预览。只看图，不读取开学日期、不自动停课、不生成调课规则。
- 主修学业审查：通过现有教务登录会话直接 GET 当前业务站点的 xsxj/zxsc.do，在应用内显示学校原表的总学分、分类学分、学位课程平均绩点、未获得课程明细和处分信息。不是成绩估算，也不需要复制链接打开浏览器。

学校重复的同名分类逐行保留，不合并求和。课程明细支持 .5、.2 这样的学分写法，以及名称中的罗马数字与括号。学校没有列出课程名单或审查结论时明确提示，不计算未知培养方案目标，不擅自认定满足毕业条件。

## 已移除

移除了前一版新增的学分目标/成绩估算、本地借阅、素质发展记录、校园生活链接、人工停课/调课、模块 JSON 编辑器及对应入口。旧本地记录没有删除，以免丢失用户资料；它们不再被读取或作用于课表、提醒、组件和日历导出。旧测试 APK 保留为独立历史文件，发布新版时不要选错版本。

开学日期默认仍为 2026-08-24，已保存的自定义日期优先。看校历、读取审查、登录和同步都不会覆盖自定义设置。

## 界面修订（2.1.7）

已删除校历页面和原图预览中的操作说明文字，保留图片预览、重试及加载错误提示。校历图片、主修学业审查两个界面顶部均显示“← 返回”：网页/APK 返回进入前的首页或设置页，切换两个模块不会丢失返回来源；小程序返回上一级页面，直接进入或返回失败时回到首页。读取审查数据时，返回按钮仍可使用。

## 查询与缓存

打开审查页时，已有登录会话会自动查询一次；“刷新审查数据”只请求这一张审查表，不重新同步全学期成绩。读取成功后按当前账号保存离线缓存，并显示读取时间。超时、登录页、无权限、表结构变化或总学分缺失时，不用空数据覆盖旧缓存。切换账号后的旧请求结果会被丢弃；数字账号与审查表学号不一致时拒绝保存。

学校 HTML 只按文本解析，不能注入脚本、表单或未知外链。没有任何学校写入、课程审核提交、借阅续借、缴费或授权链接转发。

## 小程序更新

本次删除提示和增加返回按钮只涉及界面，重新编译小程序即可，不需要重传云函数。若此前尚未部署学业审查接口，再执行下面的首次更新步骤：

1. 微信开发者工具中，右键 E:/NJUST_companion/cloudfunctions/njustSync2，选择“上传并部署：云端安装依赖”。学业审查依赖 getAcademicReview 动作以及 lib/campus-core.js、lib/campus-config.js，只编译小程序不会更新服务器逻辑。
2. 然后重新编译小程序。原有云环境配置不需要更改，也不需要新增另一个云函数。
3. 校历图片使用 https://jwc.njust.edu.cn；正式使用时核对微信后台下载合法域名。图片加载失败会提示重试，不自动改用私人图片。

当前代码在 E:/NJUST_companion/miniprogram/pages/campus/index.*，模型在 utils/campus-core.js；首页入口是 pages/dashboard/index.wxml。API 通过现有智慧理工掉线恢复机制调用，不另做验证码登录。

## 网页 / APK 更新

APK 新版为 2.1.7 / versionCode 19，Android 直接复用当前学校 Cookie 查询，不打开外部浏览器，不把密码或 Cookie 发给网页。测试包不是正式发布签名；签名不同不能直接覆盖，切勿为了测试先卸载旧版导致离线数据丢失。
