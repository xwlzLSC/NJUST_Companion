关于
南理教务助手
一个本地优先、可安装、可离线查看，并支持本机代理直连教务系统的南京理工大学教务数据平替方案。
为了避免把账号密码交给第三方服务器，浏览器版的直连登录由你自己的电脑本地 Node 服务完成；安卓安装包则改为手机本机原生联网同步，前端只负责展示与缓存。
导入同步数据
支持两种内容：1）书签脚本从教务页面复制的单模块 JSON；2）本应用导出的整份备份。导入时会自动合并，不会把其他模块清空。
添加自定义课程
自定义课程只保存在本机，不会覆盖教务处同步课表。

成绩帮助
1. 英语课默认不勾选：多数学院英语课程更偏向奖学金统计，保研更常看四六级最高分；所以初始会优先勾选非英语必修课，你也可以手动改。

2. 四六级计入规则：默认取 CET4 / CET6 历次中的最高总分，按 `总分 ÷ 710 × 100` 换算成百分制，再按 `8 学分` 计入“已选+四六级”。

3. 文本成绩换算：及格=60，中等=70，良好=80，优秀=90；同时兼容 `优- / 良+ / 良` 这类成绩。

4. 绩点公式：`<60=0.0`，`<64=1.0`，`<68=1.5`，`<72=2.0`，`<75=2.3`，`<78=2.7`，`<82=3.0`，`<85=3.3`，`<90=3.7`，`>=90=4.0`。
如何将 .ics 导入日历
iOS（苹果）：找到下载的 .ics 文件，点击即可弹出"添加到日历"。

Android：用系统日历 App 或 Google 日历打开下载的 .ics 文件导入。

Google 日历（网页）：打开 calendar.google.com → 设置 → 导入 → 上传 .ics 文件。

Outlook：文件 → 导入，选择 .ics 格式。

使用说明
这是一份给新用户的快速上手说明。账号填教务系统账号，密码填教务处密码，通常初始密码就是学号；如果你已经改过密码，就填修改后的教务密码。校园网认证是另一组账号密码，不要和教务登录混淆。
先登录，再设置学期开始日 登录成功后，课表周次、首页提示和后续同步会更准确。
01
1. 输入账号 一般填学号或教务系统用户名。
02
2. 输入密码 填教务处密码，初始密码常见为学号。
03
3. 设置学期开始日 登录后到设置页填写，周次才会自动算对。
04
4. 登录并同步 同步后会保存课表、成绩和考试到本机缓存。
常见提醒
• 登录失败先确认验证码是否刷新，再重新输入。
• 如果登录成功但课表周次不对，优先检查“学期开始日期”。
• 通知、待办和桌面组件都在设置页，登录后也可以随时查看。
